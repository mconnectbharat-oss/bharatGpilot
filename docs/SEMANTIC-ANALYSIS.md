# Semantic repository understanding

BharatGPilot extracts direct project-purpose signals from README headings and manifest descriptions, technology signals from indexed file extensions and manifests, and likely entrypoints.

These are evidence-backed signals, not claims of complete repository understanding. If relevant README or manifest content was not ingested, the system reports that no direct purpose signal was extracted from the current scope.

Future agent reasoning can use these structured facts while retaining provenance.
